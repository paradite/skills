---
name: loose-ends
description: "Check for loose ends on current task and worktree."
---

Check if there are any loose ends on current task and worktree:

- Any bugfixes or code that should be committed and submitted as PR.
- Any task-specific code that should be pushed to a remote branch but not merged to main.
- Any documentation that needs to be updated.
- Any follow up tasks that need to be created.

Remove temporary files and directories that are no longer needed. Ensure the current worktree is clean in terms of git status with nothing uncommitted.
